# Caso real desidentificado

Este recorte demonstra a organização de uma análise real de aposentadoria rural. A publicação foi solicitada pelo advogado responsável.

- [Abrir arquivo HTML](dossie.html): baixar o arquivo e abrir no navegador para usar o painel interativo.
- [Ler relatório](relatorio.md): versão legível diretamente no GitHub.
- [Dados estruturados](dossie.json): base do painel e do relatório.

Nomes, localidades, identificadores, datas, anos, valores, áreas, quantidades e dados familiares foram suprimidos na edição pública. As marcações indicam supressão e não representam valores substituídos ou fatos novos. A ordem dos eventos, os IDs e as relações foram preservados. Não há PDFs originais, transcrições integrais, mapa de substituições ou conferências pessoais do navegador neste diretório.

O conteúdo reproduz a análise importada, sem nova validação jurídica ou conferência dos autos. Não é modelo de conclusão jurídica nem demonstração de êxito. O contexto pode permitir reconhecimento por quem já conheça o caso; a desidentificação não constitui garantia de anonimização irreversível.

Foram preservados 31 documentos, 24 fatos, 6 requisitos, 4 teses, 145 relações, 18 marcos e 3 contradições. Quando a íntegra não está incorporada, a ficha informa a ausência. Vincular PDF é uma ação local e temporária do usuário, sem upload pelo painel.
