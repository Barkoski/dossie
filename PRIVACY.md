# Politica de Privacidade — Dossie Juridico Auditavel

Ultima atualizacao: 1 de outubro de 2026.

## Escopo

O Dossie Juridico Auditavel e um plugin composto por instrucoes e arquivos locais de Skill. Nesta versao, o plugin nao possui servidor MCP proprio, nao exige conta externa e nao envia dados do caso para infraestrutura operada por Lucas Barkoski.

## Dados do usuario

O plugin trabalha apenas com o conteudo disponibilizado no ambiente em que esta sendo executado. O tratamento de conversas, arquivos e demais dados pelo ChatGPT ou Codex segue as configuracoes, politicas e termos aplicaveis ao produto da OpenAI utilizado pelo usuario.

O plugin nao implementa telemetria propria, publicidade, rastreamento de terceiros ou banco de dados externo.

## Dados juridicos e sigilosos

Dossies podem conter dados pessoais, documentos processuais e informacoes protegidas por sigilo profissional. O usuario e responsavel por avaliar se pode inserir, armazenar, exportar ou compartilhar esses dados no ambiente utilizado.
